*用户 × 需求 × 场景 · 市场 · 商业模式 · 竞品全景*

> **关于数据：** 本文为作者研究笔记。带来源链接的数据已于 2026-10-16 核对，未找到可核查来源的数据已删除。市场规模预测来自商业研究机构，不同机构口径差异很大，不代表行业共识。

# 执行摘要

陪伴类AI产品（AI companion）是以建立情感联结、提供情绪价值与缓解孤独为核心目标的AI应用与硬件的统称。本报告系统梳理其产品分类、用户与需求特征、典型使用场景、市场规模与趋势、商业模式逻辑以及全球现存竞品格局。核心发现如下：

**市场规模：** 各机构对市场口径分歧很大。仅“AI陪伴App”一项，2025年估值就从约42亿美元到172亿美元不等；更宽口径的“AI陪伴整体市场”一家机构估计2025年约368亿美元、2035年约5525亿美元（CAGR≈31%）；AI陪伴机器人市场另一家机构估计从2024年约108亿美元增至2034年约942亿美元（CAGR≈24%）。

**用户需求：** 年轻人是主力。Pew 2026年调查显示，18–29岁成人中有20%曾向聊天机器人寻求情感支持或建议，明显高于年长群体。孤独感与“被倾听感”是首要动机，其次为无评判倾诉空间、随时响应、定制化亲密关系等。

**商业模式：** 以订阅制（约 $10–20/月）为主流，辅以抽卡/Gacha、虚拟商品、代币消耗与硬件销售。收入高度集中：头部10%的App贡献了约89%的品类收入。

**竞争格局：** 头部App包括Replika、Character.ai、MiniMax旗下的星野/Talkie等；行业自2025年起进入“调整期”，部分产品收缩或整改，面临“体验—合规—营收”不可能三角。硬件方向在养老、儿童等细分人群融资活跃，但大多尚未大规模商业化。

# 一、范围界定与产品分类框架

本研究将陪伴类AI产品定义为：以人与AI之间的情感联结为设计目标，具备拟人化人格、持续记忆、情感共情能力与主动互动机制的产品。其与工具型AI助手（如通用问答助手）的区别在于强调“关系性”与“情绪价值”。

# 二、用户/需求/场景分析

## 2.1 用户画像

| **维度** | **特征与数据** |
|---|---|
| 年龄 | 年轻人为主力。[Pew 2026年调查](https://www.pewresearch.org/chart/1-in-5-adults-under-30-say-they-get-emotional-support-from-chatbots-higher-than-for-older-adults/)：18–29岁成人中7%用聊天机器人获得陪伴、20%用于情感支持或建议；50–64岁与65岁以上分别仅2%与1%用于陪伴。 |

## 2.2 核心需求与心理动机

参考哈佛商学院 De Freitas 等人的研究（[AI Companions Reduce Loneliness](https://www.arxiv.org/pdf/2407.19096)，工作论文）及其他公开研究，用户使用AI陪伴产品的动机可归纳为以下层次：

| **动机层级** | **具体表现** |
|---|---|
| 缓解孤独感 | De Freitas 等人的实验发现，与AI陪伴对话缓解孤独的短期效果与真人互动相当，优于看视频等其他活动；“感到被倾听”是关键中介变量，作用大于聊天机器人本身的能力。研究也指出效果是即时的，未证明能长期降低孤独感。 |
| 无评判的安全空间 | 可在不担心被评判的前提下分享秘密、羞耻经历与负面情绪。 |
| 全天候可用性与即时响应 | 无需预约、秒回，满足紧急情绪支持需求（如深夜焦虑、失眠）。 |
| 定制化亲密关系 | 可自定义对方性别、外貌、性格与人设，满足恋爱幻想与乙女向审美需求。 |
| 社交焦虑缓冲与练习场 | 对现实社交恐惧者，AI是低压力的社交练习对象与过渡性客体。 |
| 陪伴的稳定性与可控性 | AI不会背叛、离开或产生不可控情绪，关系边界清晰可控。 |
| 功能性延伸 | 语言练习伙伴、写作/创作陪练、日程提醒与生活记录助理。 |

## 2.3 典型使用场景

| **场景** | **用户行为** | **产品侧重** |
|---|---|---|
| 深夜情绪倾诉 | 用户在独处时刻倾诉工作/感情压力，获得共情回应 | 长期记忆、温暖人设、文本+语音 |
| 虚拟恋爱/亲密关系 | 与自定义形象的AI发展“恋爱关系”，发送消息、照片、语音甚至“视频通话” | Replika、Kindroid |
| 剧情沉浸式互动 | 选择/创建角色进行剧本杀式对话（霸总、古风、奇幻） | 星野、Character.ai、筑梦岛 |
| 儿童教育与成长陪伴 | 孩子提问、讲故事、口语练习、识字启蒙 | 带情感认知的小机器、智能音箱 |
| 老年防孤独关怀 | 老人日常聊天、服药提醒、联系子女、播放戏曲音乐 | ElliQ、LOVOT类适老机器人 |
| 虚拟宠物养成 | 喂养、装扮、互动，培养责任感与情感寄托 | Tolan、机器狗 |
| 心理疗愈辅助 | 情绪日记、CBT式对话、冥想引导（非替代专业治疗） | 内置疗愈模块的聊天AI |

## 3.2 增长驱动因素

**社会结构变化：** 全球单身人口持续上升、原子化社会加剧、老龄化提速——据[世界卫生组织](https://www.who.int/mediacentre/factsheets/fs381/en/)，到2030年全球约每6人中就有1人年龄在60岁以上，养老照护缺口催生刚性陪伴需求。

**技术成熟度：** 大语言模型、多模态生成（语音/图像/视频）、长期记忆架构与端侧推理成本下降，使高保真陪伴成为可能。

**消费代际变迁：** 年轻一代对数字原生关系的接受度高，“情绪价值”成为独立消费类别，愿意为情感体验付费。

**头部大厂入场与资本推动：** 百度（月匣）、字节（豆包）等互联网公司布局，资本在细分硬件方向持续注资。

## 3.3 区域市场差异

| **维度** | **海外市场** | **中国市场** |
|---|---|---|
| 主导形态 | 一对一恋爱/情感陪伴 | 角色扮演+乙女向+抽卡游戏化 |
| 审美与叙事 | 西方个人主义浪漫关系 | 东方二次元叙事、剧情沉浸 |
| 变现偏好 | 月度订阅 | 抽卡/月卡/虚拟道具混合 |
| 硬件热度 | 养老陪伴机器人较早落地 | 儿童陪伴机器人融资活跃，C端普及仍在爬坡 |
| 监管环境 | GDPR/COPPA/FTC执法 | 生成式AI备案、内容安全审查常态化 |

## 3.4 发展趋势

- 多模态沉浸升级：实时语音通话、3D动态角色、视频互动将从付费点走向标配。
- AI+硬件深度融合：养老、儿童、特殊人群的陪伴机器人进入商业化验证期。
- 垂直细分取代大而全：通用聊天陪伴趋于红海，面向老人/儿童/疗愈/宠物的垂直产品获得更多资本认可。
- 创作者经济平台化：UGC角色/智能体市场与创作者分成机制成为留存关键。
- 监管常态化：内容安全、年龄验证、数据合规成为长期经营的前提，“合规—体验—营收”成为行业长期张力。

# 四、商业模式分析

## 4.1 盈利模式全景

| **模式** | **说明** | **代表产品** |
|---|---|---|
| Freemium订阅 | 免费基础聊天的同时提供高级人设/语音/无限对话等付费权益（主流模式） | Replika Pro（约$19.99/月）、Character.ai c.ai+（$9.99/月）、Nomi、Kindroid（约$13.99–15.99/月起） |
| 抽卡/Gacha | 通过“抽卡”解锁稀有角色/语音/记忆，依赖重复抽取刺激消费 | 星野（星念许愿池）、Talkie |
| 虚拟商品与定制 | 头像服饰、背景、音色包、个性化道具等 | 多数二次元审美产品 |
| 代币/积分消耗制 | 按条/按次扣费，适合高频轻度用户 | 部分出海产品 |
| 广告 | 免费版插屏激励广告，补贴推理成本 | Character.ai免费版 |
| 数字人克隆/B端授权 | 为网红/机构克隆AI分身并提供企业API接口 | 小冰 X Eva、Character.ai早期曾尝试 |
| 硬件销售+服务订阅 | 一次性硬件收入+持续性服务费 | LOVOT（机身+月费）、ElliQ、儿童陪伴机器人 |

订阅价格据 2026 年第三方汇总（如 [aicompanionpick.com](https://aicompanionpick.com/ai-companion-pricing-free-vs-premium-2026)），各产品按地区、渠道与促销不同，以官方页面为准。

## 4.2 产业链结构

| **环节** | **角色** | **关键玩家/要素** |
|---|---|---|
| 基础设施层 | 云算力与GPU供应 | 云厂商、芯片厂商 |
| 模型层 | 通用大模型与垂类情感模型 | 通用LLM厂商、情感模型初创 |
| 平台层 | 记忆架构、多模态引擎、安全审核、内容治理 | 各平台自研/采购 |
| 应用层 | 直面用户的陪伴App与硬件 | Replika、星野、ElliQ等 |
| 渠道层 | 应用商店、自有渠道、硬件零售 | Apple/Google Store、官网、电商 |
| 衍生层 | IP周边、线下活动、真人COS联动 | 部分平台探索 |

## 4.3 商业化核心挑战

- 算力成本高企：模型开支与有限的订阅收入难以平衡。据 [Sacra 估计](https://sacra.com/c/character-ai/)，Character.ai 约2000万月活对应的年化收入仅约3000万美元。
- “不可能三角”：用户体验（沉浸感/尺度）、内容合规审查与营收增长三者互相挤压。
- 留存与黏性：大模型“情感共鸣”仍处模仿阶段，用户新鲜感消退快，需靠角色生态与多模态内容维持。
- 获客成本上升：买量ROI承压，依赖口碑与社交流量的自然增长愈发困难。

## 5.3 竞争格局总结

软件赛道已进入“马太效应+出清期”：Appfigures 数据显示头部10%的App拿走了约89%的收入，大量中小应用难以盈利；部分大厂产品也在收缩，例如据36氪报道，阶跃星辰已停止对角色扮演产品“冒泡鸭”的大范围投入，团队并入其他产品（[凤凰网转述](https://finance.ifeng.com/c/8juFmAVSJxg)；公司回应称为“收敛产品方向”）。行业普遍陷入“合规—体验—营收”不可能三角，监管趋严，筑梦岛被约谈即是一例。硬件赛道则相反，在养老、儿童、宠物等细分场景资本仍在早期密集布局，但除LOVOT、ElliQ外大多未形成规模化收入。国内厂商在出海与本土竞争并存，监管合规是长期前提。

# 六、结论与建议

**需求真实、赛道长期存在。** 孤独缓解与情感陪伴是人类的长期需求，技术成熟度与接受度双升，市场仍处于扩容期。但短期处于资本退潮后的筛选阶段，烧钱换量的模式难以为继。

**对创业/入局者的建议：**

1. 切入高支付意愿的垂直场景（银发陪伴、儿童教育、心理健康、宠物），而非泛聊天；
2. 将“长期记忆+多模态”作为体验护城河；
3. 构建UGC角色生态与创作者分成提升黏性；
4. 变现上采用订阅为主、抽卡/虚拟商品为辅的组合，并探索B端（企业员工关怀、医疗机构辅助）；
5. 把合规与关系伦理（防沉迷、危机干预、透明度）当作产品能力而非成本。
