# Reading font licenses

The reading fonts are self-hosted from Fontsource packages; the app does not request fonts from a third-party service.

- Source Serif 4 — `@fontsource-variable/source-serif-4@5.3.1`, SIL Open Font License 1.1. License text: [OFL-Source-Serif-4.txt](OFL-Source-Serif-4.txt).
- Noto Serif SC — `@fontsource-variable/noto-serif-sc@5.3.1`, SIL Open Font License 1.1. License text: [OFL-Noto-Serif-SC.txt](OFL-Noto-Serif-SC.txt).

Fontsource packages are distributed by the Fontsource project; the underlying font families remain under the OFL. Keep these files with the app and any public snapshot.
