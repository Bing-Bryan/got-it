## 哪句不懂，划哪句

选中文字或框选 PDF，在原句旁直接提问、查证并留存

**[直接在线体验 →](https://gotit.bingbryan.com/)**

打开网页即可使用，无需安装

阅读时，遇到一个陌生概念、一段难懂的论述，或一个想核对的数字，不必离开文章去切换工具。把 Markdown、PDF 或公开网页放进同一个阅读库，围绕正在读的内容，把问题弄明白，再接着往下读。

### 围绕原句，选择你需要的帮助

- **解释一下：** 说明陌生概念或难懂段落，用容易理解的语言理清含义与上下文。
- **查找来源：** 寻找数字、观点的出处，查看找到的资料是否支持原句；没有足够依据时，也会保留这一结果。
- **问一问：** 围绕选区提出具体问题，比如比较两个说法、追问一个原因，或弄清某一步推导。

回答作为知识贴留在对应原句旁。读到别处后，可以回来查看解释、问题和来源，不用重新寻找当时的上下文；下次打开材料，也能接着上次的位置继续读。

### 三步开始阅读

1. 打开 Markdown / PDF 文件，或粘贴公开网页链接。
2. 选中想弄明白的文字，或框选 PDF 中的图片、图表。
3. 选择解释一下、查找来源，或写下自己的问题。

值得留下的原句可以收藏，外文材料可以切换全文译中，让阅读和回看都更顺手。

材料、知识贴和阅读进度保存在当前浏览器，原文件不变
