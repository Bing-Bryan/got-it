# 2026-10-19：简化首页与真实阅读案例

首页集中呈现导入材料、继续阅读和解释／查找来源／提问三个入口，完整阅读库与收藏在抽屉中展开。公开链接可直接从首页读取，显示原位进度与错误；成功保存后进入正文。

三张功能卡及“看看怎么用”共用真实公开报告选区与有限真实采样的回答快照。打开页面与教学浮层不发起模型请求；读者主动选择材料、选区和问题后才生成自己的回答。

查找来源示例直接展示结论、范围和一条经过原文匹配的arXiv作者摘要来源，完整回答、理由和过程可展开。该结果为部分支持，仍受摘要缺少实验细节等限制，不将搜索完成或引用匹配解释成完整核实。解释与提问保留真实回答原文。

首页与教学浮层在桌面及390px窄屏核对，链接导入、保存恢复和异常状态按本轮变更验证。README保留此前已发布的图片与引用，属于历史界面；本次没有替换截图或将新的截图视为已确认公开材料。
