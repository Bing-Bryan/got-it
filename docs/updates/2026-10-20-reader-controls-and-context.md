# 阅读控件、材料列表与回答上下文

本次更新统一了阅读页同类控件的选中、悬停、按压和键盘焦点反馈。分类标签适应面板宽度，翻译入口在 Markdown、网页和 PDF 中保持一致；成功保存统一显示“已保存”，失败和部分保存继续单独说明。

文件切换浮层利用可用高度，公开样例固定在列表底部并可搜索。材料支持两步确认移出阅读库、撤销或恢复；原文和阅读成果保留，移出状态刷新后仍有效。知识贴删除也采用固定尺寸的两步危险确认。

普通 Markdown / 网页的主动解释和提问会在有限预算内补充相关定义及必要相邻段落，帮助理解标题中的术语；不会默认发送整篇。材料不足时，回答应说明当前提供片段的缺口，避免推断整篇文章没有相关信息。普通托管问答不会自动联网。

问一问输入态支持点击外部空白或按 Esc 关闭。全文翻译由明确点击直接开始，自动翻译偏好保持独立且默认关闭；切换或刷新已有材料不会自动生成回答。
