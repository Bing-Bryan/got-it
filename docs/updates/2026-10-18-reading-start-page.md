# 从起始页加入材料，接着上次的阅读

2026-10-18

打开 got it 先进入起始页。空库用一段带页边知识贴的介绍展示阅读方式，可以主动选择文件、加入公开链接，或打开可选样例；不会自动载入案例或发起提问。

有材料时，起始页显示上次阅读位置附近的原文或译文、已经保存的知识贴，以及最近材料和名称搜索。“查看全部”在中央展开完整列表。顶部保留品牌与全部收藏，首页不显示阅读侧栏；进入阅读后，原导航和固定偏好继续保留。

阅读中点击左上标识可返回起始页，“回到那一段”继续原位置。返回前保存失败会留在阅读页面，明确提示并保留应急草稿；同一标签刷新恢复阅读，新打开应用进入起始页。

本次沿用浅暖白纸面和系统字体，没有引入新的外部字体。原文件、已有知识贴、浏览器备份和本机阅读库边界不变；托管版成果仍只保存在当前浏览器，清除数据前请下载完整备份。没有新增账号、云同步或自动模型请求。
