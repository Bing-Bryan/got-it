# 从起始页加入材料，接着上次的阅读

2026-10-18

打开 got it 先进入起始页。空库用一段带页边知识贴的介绍展示阅读方式，可以主动选择文件、加入公开链接，或打开可选样例；不会自动载入案例或发起提问。

桌面起始页分为三部分：左侧材料／收藏标签、名称搜索与样例；中央保留产品介绍和文件／链接入口；右侧首访显示可切换的演示知识贴，回访显示上次阅读位置附近的原文或译文及已存知识贴。两侧内容独立滚动，中央保持可见；窄屏将辅助内容折叠。完整收藏管理保留原入口，进入阅读后原导航和固定偏好继续保留。

阅读中点击左上标识可返回起始页，“回到那一段”继续原位置。返回前保存失败会留在阅读页面，明确提示并保留应急草稿；同一标签刷新恢复阅读，新打开应用进入起始页。

本次沿用浅暖白纸面和系统字体，没有引入新的外部字体。原文件、已有知识贴、浏览器备份和本机阅读库边界不变；托管版成果仍只保存在当前浏览器，清除数据前请下载完整备份。没有新增账号、云同步或自动模型请求。

回访也保留“原文不动，弄懂的过程留在原句旁。”及简短产品介绍。“上次读到”和文章标题分层显示，保存的知识贴对应续读内容；没有知识贴时只显示简短提示，不留空侧栏。长标题与中文译摘在窄屏仍能直接找到续读入口。

PDF阅读模块或组件发生错误时，现在只替换阅读区并明确提示，保留导航以切换材料。重新加载前先保存；保存失败不会继续重载。阅读控件与浮层补齐浅暖白中性背景，保留状态色和键盘焦点，PDF原页不着色。
