# 网页图片快捷操作与更安静的选区提示

本次更新让网页正文中已保存的图片成为可直接操作的内容对象：鼠标移到图片上或键盘聚焦图片时，图片下边缘会浮现收藏、解释一下、查找来源、问一问和关闭。操作条只在明确点击后发送；只悬停或打开操作条不会请求模型或搜索。触屏设备在图片右下角提供可点击的图片操作入口，点击图片本身仍打开现有大图预览。

图片收藏保存图片身份、原文版本、说明与时间，刷新或重开后可回到同一张图；收藏不依赖模型是否可用。解释和问一问绑定该图片，图片知识贴以不遮挡原图的轮廓标记，右侧摘录标明“图片”。同一篇文章中 alt 或图注相同的不同图片保持独立。

选区浮窗不再重复显示发送说明；完整的文字、图片与联网查询发送范围统一放在「保存与隐私」。托管模式下，图片没有可检索的 alt、图注或邻近文字时，“查找来源”会在发送前说明不可用，不使用空查询，也不声称完成反向图片搜索。

公开测试使用受控夹具；真实模型读图、托管线上读图和实体触屏验证范围以发布记录为准。自动测试通过不代表所有设备和浏览器均已实机验收。
