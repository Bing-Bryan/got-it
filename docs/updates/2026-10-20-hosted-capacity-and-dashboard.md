# 托管容量与私人运营看板

2026-10-20

托管体验完成了容量与观测升级：问答、翻译和网页读取的并发准入更清晰，翻译与非问答任务不会占用为问答保留的最后一个槽位；容量不足时会返回可理解的繁忙状态，不扣次数、不预留费用，也不会自动排队重试。

本次同时上线了仅运营者可见的只读健康与产品汇总入口。它只通过本人 SSH 隧道和本机回环查看器打开，公网不提供管理页面或运营接口；查看过程不调用模型、搜索、抓取或发信，也不会改变读者的阅读成果。健康视图区分应用进程与主机，展示真实采样时间、样本量、费用确认与在途预留，并对缺失、过期或不可用状态明确标注，不把未知显示为正常。

原有的每日费用上限、单浏览器额度、入口限速和数据白名单保持不变。上线验证覆盖公共阅读入口、静态资源与 API 身份、公网运营接口拒绝、私有入口读取、首样本与第二次真实采样、同窗口主机 CPU/内存/数据文件系统读数，以及采样失败、过期、历史上限和恢复的隔离验证。

范围限制：没有进行生产压力测试、长期稳定性观察或上线后的真实付费模型调用；容量默认值是目标配置，不等于已测得的生产容量。运营看板仍只对本人开放。
